EduTrack – Student Attendance and Results Management System

About the Project

EduTrack is a student management website designed to help students track their attendance and academic results in one place.

Features

- Student Login
- Student Dashboard
- Attendance Tracking
- Results Management
- User-Friendly Interface

Technologies Used

- HTML
- CSS
- JavaScript

Project Files

- login.html – Student Login Page
- dashboard.html – Student Dashboard
- style.css – Website Styling
- script.js – JavaScript Functionality

Purpose

The main purpose of EduTrack is to help students monitor their attendance and academic performance.
